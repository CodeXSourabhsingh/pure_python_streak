# pure_python_streak

## Pure Python Advanced Streak - 7 Projects in 7 Days

This repository contains 7 working Python projects built using **pure Python only**. No Pandas. No SQL. No external data libraries. Just classes, objects, APIs, and logic.

## Projects

1. Library Management System (OOP) - Classes, objects, state management, try/except
2. Weather Data Fetcher (API) - Fetch real-time data from OpenWeatherMap API
3. ETL Data Pipeline (Pure Python) - Extract, transform, load without Pandas
4. Task Scheduler with Priority Queue - Data structures, heap logic
5. Simple Web Scraper - HTML parsing, requests library
6. Automated Report Generator - File I/O, formatted output
7. Bioinformatics Tool Integrator - Combining previous tools into one system

## Tech Stack

- Python
- Pure Python only (No Pandas, No SQL)
- APIs (requests)
- Git / GitHub

## Purpose

I spent 6 days building 10 advanced bioinformatics projects. Now I am rebuilding my Python foundation from scratch using pure logic. No shortcuts. No library crutches.
